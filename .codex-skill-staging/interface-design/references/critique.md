# Critique

Run this before presenting a substantial interface change.

## Craft Questions

- What still feels template-like?
- Which part would survive a swap to a generic dashboard layout?
- Which element actually carries the product's signature?
- Is hierarchy visible when you squint?
- Are borders or shadows louder than the content?

## Rebuild Triggers

Iterate before showing if:

- typography could be swapped with a default stack without changing the feel
- navigation feels like scaffolding instead of product structure
- metrics are just labels with big numbers and no story
- accent color is decorative rather than meaningful
