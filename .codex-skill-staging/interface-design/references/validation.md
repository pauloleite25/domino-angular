# Validation

Use this file after a design task or before saving patterns.

## When To Save `.interface-design/system.md`

Save when:

- a component pattern appears 2 or more times
- spacing, depth or typography rules are clearly stable
- the product direction is no longer exploratory

Do not save when:

- the design is still being tested
- the user is iterating quickly on one-off experiments
- values are likely to change in the next step

## Review Pass

Check:

- does the implementation still match the stated intent?
- does the signature show up in multiple concrete places?
- do tokens sound product-specific?
- does the UI still work when content grows or shrinks?
