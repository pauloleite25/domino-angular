## Full description

```text
Domino Mesa traz uma experiencia de domino focada em partidas rapidas e interface clara para celular.

Voce pode jogar de duas formas:

- VS CPU para entrar direto em uma partida local
- Salas online simples para criar uma mesa, compartilhar o codigo e jogar com amigos

Recursos principais:

- Partidas locais contra CPU
- Salas privadas com codigo, senha e escolha de posicao
- Suporte a ate quatro participantes humanos
- Espectador em salas online
- Historico de jogadas, placar e reacoes durante a partida
- Interface pensada primeiro para mobile

O Domino Mesa foi construido para reduzir friccao: abrir, escolher o modo e comecar a jogar.
```
