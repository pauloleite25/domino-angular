# Review notes

## App access

Texto pronto para colar:

```text
O app nao exige login tradicional para funcionar.

Para revisar o jogo, o modo local pode ser acessado imediatamente pela tela inicial usando o botao "VS CPU".

Os recursos online sao opcionais e dependem de backend disponivel. Neles, o jogador informa apenas um nickname casual para criar ou entrar em uma sala privada.

Nao ha conta obrigatoria, paywall, codigo promocional nem credencial fixa de teste.
```

## Notes to reviewer

```text
Domino Mesa e um jogo de domino com modo local contra CPU e modo online casual por salas privadas.

Fluxo minimo para avaliacao:
1. Abrir o app
2. Tocar em "VS CPU" para iniciar uma partida local imediatamente

Fluxo online opcional:
1. Tocar em "Criar sala" ou "Entrar na sala"
2. Informar nickname, codigo da sala e senha
3. Jogar com a sala sincronizada pelo backend
```

## Target audience note

Resposta recomendada: evitar declarar publico principal infantil, a menos que voce queira adaptar o app inteiro para a politica de Families do Google Play.
