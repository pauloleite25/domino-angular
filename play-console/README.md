# Play Console package

Este diretorio concentra o material que voce vai colar na Play Console quando a conta estiver pronta.

Arquivos:

- `store-listing.md`: titulo, descricao curta, descricao completa e assets necessarios.
- `data-safety.md`: respostas-base para o formulario de seguranca de dados.
- `review-notes.md`: texto pronto para o campo de acesso do app e notas ao revisor.
- `submission-checklist.md`: checklist final antes de publicar.

Politica de privacidade publica:

- arquivo local: `src/assets/legal/privacy-policy.html`
- URL esperada apos deploy: `https://SEU_DOMINIO/assets/legal/privacy-policy.html`

Bundle Android pronto para upload:

- `android/app/build/outputs/bundle/release/app-release.aab`
